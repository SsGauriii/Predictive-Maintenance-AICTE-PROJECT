Place the Kaggle dataset CSV here:
  data/predictive_maintenance.csv

Download from:
  https://www.kaggle.com/datasets/shivamb/machine-predictive-maintenance-classification

Expected columns:
  UDI, Product ID, Type, Air temperature [K], Process temperature [K],
  Rotational speed [rpm], Torque [Nm], Tool wear [min], Machine failure,
  TWF, HDF, PWF, OSF, RNF, Failure Type

If this file is absent the pipeline auto-generates synthetic data
matching this schema for pipeline validation purposes.
